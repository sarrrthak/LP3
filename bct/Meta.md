# Practical: Create Your Own Wallet Using MetaMask

Aim: To create a cryptocurrency wallet using MetaMask.

Requirements: Google Chrome, MetaMask extension and internet connection.

## Procedure

1. Open Google Chrome and visit [MetaMask official website](https://metamask.io/?utm_source=chatgpt.com).
2. Click Download and select Chrome.
3. Click Add to Chrome to install the MetaMask extension.
4. Open the MetaMask extension from the browser toolbar.
5. Click Create a new wallet.
6. Accept the terms and conditions.
7. Create and confirm a strong password.
8. MetaMask will generate a 12-word Secret Recovery Phrase. Write it down and store it safely.
9. Confirm the Secret Recovery Phrase in the correct order.
10. Complete the wallet setup.
11. Open the MetaMask dashboard to view your newly created wallet.
12. Click the account name to view and copy your public wallet address.

Result: Successfully created a cryptocurrency wallet using MetaMask with a unique public wallet address.

Note: Never share your Secret Recovery Phrase or private key with anyone.
